# Вариант с паролем — лежит готовым, но не используется

17.08.2026 дашборд был перенесён с GitHub Pages на Netlify за пароль, а к вечеру
возвращён обратно на Pages. Причина возврата: **Netlify не открывается без VPN**,
а Анне нужен доступ без него. Решение её, принято с полным знанием последствий.

Здесь всё, что было сделано, — работает, проверено, ждёт своего часа.

## Что в папке

| Файл | Что делает |
|---|---|
| `functions/_auth.js` | пароль (scrypt) и пропуска (HMAC, 30 дней) |
| `functions/login.js` | вход по паролю, ставит cookie |
| `functions/app.js` | отдаёт саму страницу дашборда по пропуску |
| `functions/data.js` | отдаёт цифры по пропуску |
| `functions/metrics.js` | слепок прошлых цифр: по пропуску или по служебному ключу сборки |
| `functions/stamp.js` | метка свежести |
| `../web/login.html` | форма входа |
| `../netlify.toml` | адреса, заголовки, приватный каталог |
| `../tests/авторизация.test.mjs` | 16 проверок, все проходили |

Настройки (`PASSWORD_HASH`, `TICKET_SECRET`, `BUILD_TOKEN`) остались на сайте
`rezerv-dashboard.netlify.app`. Сам сайт живой, но обновляться перестал —
автообновление снова публикует на GitHub Pages.

## Что важно помнить, если будете возвращаться

**Пароль поверх статики бесполезен.** На Pages цифры вшиты прямо в страницу
и скачиваются раньше, чем выполнится любая проверка. Поэтому в этом варианте
открытой оставалась только форма входа (3693 символа), а сам дашборд и данные
отдавались функциями.

**Имя cookie только латиницей.** Было «пропуск» кириллицей — браузер молча
выбрасывал, вход не срабатывал, выглядело как неверный пароль.

**Сравнение с прошлой сборкой должно жить.** Сборка скачивает слепок прошлых
цифр и сверяет с новыми — это главная защита от тихих поломок (04.08.2026
дебиторка 92,7 млн вместо 1,6 млн при всех зелёных проверках). Поэтому у сборки
свой служебный ключ, отдельный от пароля.

**Публикация набело с ноутбука Анны отвечала Forbidden.** Черновик проходил.
Обход: собрать черновиком и перевести в основной через `restoreSiteDeploy`.

## Если понадобится без VPN и с паролем

Netlify отпадает. Остаётся сервер Timeweb `5.129.221.19`, где живёт база
исполнителей: он открывается без VPN. Но там нужен поддомен и сертификат —
сейчас сервер отдаёт только http, а по http пароль летит открытым текстом.
